# AgroLake 农智数湖

兴智杯无人农场数据治理项目。围绕农田影像、地块属性与复核记录，制作来源可查、质量可解释的数据治理和田块识别原型。

## 当前进度

正式开发已启动。已检查本机环境，创建独立 Python 3.11 环境，取得并核对 FTW 1.4.3 发行包、8 波段测试影像与 v1 CC-BY 权重。依赖安装及真实推理尚未通过验收；网页、SQLite 治理流程和 DeepSeek 接入继续开发。

## 开发方式

WorkBuddy 按明确任务编写代码并运行，Codex 负责技术协调、代码复核和实际验收。每个通过检查的功能保存独立 Git 提交，再同步到本私有仓库。具体流程见 [GitHub 协作流程](docs/GitHub协作流程.md)。

主要交付目标为 Streamlit 网页、SQLite 目录与质量治理、真实 FTW 识别以及基于入库事实的 DeepSeek 问答和报告。完成状态以实际代码和运行证据为准。启动说明会在可运行版本验收后补入。

环境、原始数据、权重、数据库和本地协作资料由 `.gitignore` 排除。仓库保存审阅过的源码、配置样例、依赖记录和使用说明。

本仓库保留最初的兴智杯 README 与初始提交历史。
