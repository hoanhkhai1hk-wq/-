# AgroLake 农智数湖

兴智杯无人农场数据治理项目。围绕农田影像、地块属性与复核记录，制作来源可查、质量可解释的数据治理和田块识别原型。

## 当前进度

第一版治理原型已可运行：JPG/PNG 影像、CSV 属性、JSON/TXT 记录接入，内容去重与版本留痕，质量检查、单位和地物类别标准化，场景关联、问题处置复检及报告导出。36 项核心验收通过；演示资料全部为人工合成，仅用于操作与规则验证。

独立CLI识别模块已对公开FTW 8波段测试影像与v1 CC-BY权重完成真实CPU推理，输出背景/田块内部/边界掩膜、预览及候选连通区域像素表；通过18项软件测试。输入要求双时相多波段，普通RGB治理页面不代替该模型。用法与限制见 [模型适配说明](docs/模型适配说明.md)。

独立本地识别服务已完成HTTP上传、串行真实推理、SQLite运行与候选区域存储、结果查询和五种产物下载。25项服务软件测试通过，另经真实模型HTTP作业、错误输入、异常退出恢复及下载一致性验证。启动与演示见[识别服务说明](docs/识别服务.md)。

网页第 8 页“田块识别”已接入上述识别服务：可选本机公开适配样例或上传 8 波段 TIFF，提交后查看预测图、候选区域像素表并下载五种产物；可查询历史、按同号重试或明确新建任务。12项客户端测试、10项整改回归及7步页面流程通过，真实权重网页流程40项检查通过。另经真实浏览器验证上传、下载摘要、失败输入、历史恢复及断开重连。启动与边界见[网页识别说明](docs/网页识别.md)。

网页第 8 页新增**人工复核记录**面板：可对成功识别任务整体或某个候选区域，填写结论（可用/存疑待核实/不采用）、署名与原因，查看当前意见和不可覆盖的历史，导出 UTF-8 CSV/JSON。仅显式保存才写入；改回旧意见会追加，重复点击和同号重试不多写。每任务最多500条历史，导出取固定快照。11项复核API测试、9项Codex整改回归、6步页面流程、29项真实权重检查通过；另经真实浏览器保存、下载与旧库升级、重启恢复核对。人工意见不改模型输出，不代表真值、精度提升或真实面积；署名不是已认证身份。用法见[人工复核说明](docs/人工复核.md)。

网页第 8 页新增**整改复跑与前后对照**面板：在已成功、已登记治理血缘且有最新存疑/不采用意见的作业上，可显式创建一条不可覆盖的修订并另起同模型新作业，查看真实排队/运行/失败/中断/成功与前后四类像素对照；整页重载后可按记录“确认原提交（同号）”，失败/中断子作业只读显示整改来源。仅显式点击才 POST，普通刷新/下载不写。24项客户端测试、14项客户端完整性探针、5项页面回归与页面 AppTest 通过（合成 fixture，非真实模型）。提交状态机另加固：每个作业只保留一个当前意图，内容变化（含 A→B→A）一律新号/新版本；回执未知（含 HTTP 5xx、prepared）锁新意图，未登记治理血缘不提供创建入口，超限替换文件禁整条提交；当前意图纳入替换文件名，成功提示按作业隔离；客户端要求必需字段存在且 SHA 只接受字符串。NoData 显示父/子 255 类像素、四类合计分母与实际占比，缺证据不补零。6项面板提交状态回归通过（见[中文导航](中文导航.md)）。人工意见不是真值；不报精度/平方米/自动修复成功，原输入/模型/意见/治理快照不改。用法见[整改复跑说明](docs/整改复跑.md)。

DeepSeek、真实农业样本精度评估及参赛材料仍待完成。候选连通区域不等于经验证的真实田块数；没有真值，不报告准确率或模型测得的平方米面积。

另新增第一轮 **RGB 待标注准备包**：从 380 张真实 RGB 切片中按行列空间覆盖每批选 6 张，导出逐像素一致的 512×512 PNG、联系图、来源与待标注清单及零基础说明。全部样品保持未标注（`annotation_status=unlabeled`、`label_path=null`），不含任何标签或掩膜，不训练、不推理。用法与边界见 [RGB标注准备](docs/RGB标注准备.md)。

另新增 **RGB 候选掩膜与待复核副本** 准备工具：把已标注的两批 RGB 资料（Field 田块/Field ridge 田埂/Road 道路）机械转换为候选索引图（0/1/2/255，无背景类别），并把含自交或画布越界的标注单独生成为可人工编辑副本。工具只读原始文件，产物为可重建派生结果，全部标记 `semantic_reviewed=false`、`not_training_ready=true`，不划分 train/test、不训练。校验在创建输出目录前完成（`sample_id` 仅接受便携安全组件、`imagePath` 严格等于 TIFF basename），有效像素按互斥类别判定，源路径相对项目根、派生产物路径相对输出目录。用法与边界见 [RGB候选数据准备](docs/RGB候选数据准备.md)。


新增 **RGB内部拟合基线**：用户决定排除48份几何问题资料；855份候选中的121份因Fieldridge含义未确认而暂缓，734份原标签明确的图片已完成独立CPU训练、模型保存与训练样本预测。来源关系未知，未创建独立验证/测试划分，不据拟合损失报告农业准确率。选择、训练、预测与限制见[RGB内部基线](docs/RGB内部基线.md)。该模块未接入原FTW网页或改变8波段输入协议。

## 启动与试用

第8页支持“治理登记与血缘追溯”：把成功识别的输入登记单 JSON 纳入 P0 文本资产，关联资产/版本、登记时及当前质检、原输入/模型、人工复核与产物摘要，并下载追溯报告。登记不触发推理；文本登记单质检不代表 TIFF 已通过 P0 质检或已形成整改复跑闭环。操作与测试见[治理识别血缘](docs/治理识别血缘.md)。

使用 Python 3.11 与项目独立环境，按 [本地启动说明](docs/本地启动.md) 安装、生成可选演示资料并启动。启动后的本机页面地址为 [AgroLake](http://127.0.0.1:8505/)；该地址只在运行服务的电脑上有效。

试用顺序：治理概览 → 数据目录 → 场景关联 → 问题处置 → 报告导出。导入自己的文件时填写来源与场景；CSV/JSON/TXT 使用 UTF-8，CSV 每份文件对应一个场景。地块面积字段是输入声明及单位换算，不是模型测得的面积。规则与统计口径见 [数据字典](docs/数据字典.md)。

固定验收命令：

```powershell
& .\.venv-p0\Scripts\python.exe scripts/p0/run_acceptance.py
```
