## 当前优先顺序

1. **贯通治理与识别**：用明确ID关联资产/版本、质量问题、识别任务、模型/输入、区域、复核和产物。原治理TIFF与识别记录仍分开，不能仅因共用数据库便称统一治理或质量门禁已完成。
2. **完成整改复跑案例**：明确改的是数据、来源/关联、规则或处理配置，保存前后版本和复跑关系。人工注入异常必须标注，不能冒充自然业务问题。
3. **固定任务做对照**：记录数据可用性、错误发现/修复、追溯完整度、关联查询或复核耗时等，保留样本与分母。没有独立标注，不把元数据补全称为分割精度提升。
4. **补业务和材料证据**：争取实际需求和授权关联资料；公开遥感、合成治理资料、流程测试意见分开登记，再制作方案、部署截图和演示视频。
5. **按用户安排接DeepSeek**：用户选择暂不配置密钥、先本地功能；真实接通仍待验收，不用模拟回答替代。

模型当前只输出背景、田块内部和边界，道路/沟渠出现在字典不代表已被模型识别。公开样例时相身份未独立核实；候选连通区域不等于真实田块数，像素不换算平方米。
