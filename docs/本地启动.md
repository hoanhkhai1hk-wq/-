# AgroLake P0 本地启动说明

本页为原治理网页启动步骤。网页第 8 页“田块识别”已接入独立识别后端；识别服务与网页
一起启动的完整步骤见[网页识别启动与演示](网页识别.md)，接口与命令行演示见[识别服务启动与演示](识别服务.md)。

版本：RUN-1.2.0（2026-10-15）。面向 Windows PowerShell。
本说明为规则演示用途整理，尚未验证跨机器全新 clone 的实际安装结果；
请先把本仓库 clone 到任意目录，再在其根目录执行下列命令。
（app.py、agrolake/ 等均在项目根目录，所有路径以项目根为基准。）

## 一 前置：准备 Python 3.11 解释器

本项目独立环境要求 Python 3.11.x，与科研/ML 环境分离。

- 任一 Python 3.11 解释器均可（官方 python.org 3.11，或 conda 环境）。
- 本机现有 conda 环境 `hwh_ml`（Python 3.11.15），可直接作为创建 venv 的基础解释器；
  也可用 `py -3.11` 等已安装的 3.11。

## 二 创建独立环境（首次）

下面两种方式任选其一（互斥，不要同时执行）：

```powershell
Set-Location "<你clone后的项目根目录>"

# 方式A：使用 py 启动器定位 Python 3.11
py -3.11 -m venv .venv-p0
```

```powershell
Set-Location "<你clone后的项目根目录>"

# 方式B：使用 conda 环境 hwh_ml 中的 python 作为基础解释器
conda run -n hwh_ml python -m venv .venv-p0
```

若改用某个 python.exe 的完整路径，请把单个解释器路径变量放在 venv 命令里使用，
不要把整串命令当作可执行文件名：

```powershell
$Py311 = "C:\path\to\python311\python.exe"   # 示例，换成你机器上的实际路径
& $Py311 -m venv .venv-p0
```

## 三 仅首次安装锁定依赖

```powershell
.\.venv-p0\Scripts\python.exe -m pip install --upgrade pip
.\.venv-p0\Scripts\python.exe -m pip install --no-cache-dir -r requirements-p0.lock.txt
```

- `requirements-p0.txt` 只列直接依赖：`streamlit==1.50.0`、`Pillow==11.3.0`。
- `requirements-p0.lock.txt` 是这两个直接依赖及全部传递依赖的实测解析结果（实测 37 项，
  pip/setuptools 两项引导包不在 lock 内）。
- 依赖已安装后，之后启动无需重复安装。
- 不安装 GDAL、MinIO、MySQL、rasterio 或可选地图组件。

## 四 生成演示数据（全部人工合成）

```powershell
.\.venv-p0\Scripts\python.exe scripts\p0\make_samples.py
.\.venv-p0\Scripts\python.exe scripts\p0\seed_demo.py
```

- `make_samples.py` 在 `data/p0/samples_synth/` 生成样本，全部标注 `SYNTHETIC`。
- `seed_demo.py` 将它们导入演示库，来源统一记为 `SYNTHETIC-人工合成演示`。
- 演示库 `data/p0/` 内全部为人工合成样本，仅用于规则与流程演示/测试，
  不代表真实农业效果，也不能作为业务结论证据。

## 五 运行测试（项目内独立目录）

```powershell
.\.venv-p0\Scripts\python.exe scripts\p0\run_acceptance.py
.\.venv-p0\Scripts\python.exe scripts\p0\ui_apptest.py
```

- 测试与 AppTest 都写入项目内 `reports/p0/` 下的独立目录，不使用系统临时目录，
  也不改动演示库。

## 六 启动操作网页

前台运行：

```powershell
.\.venv-p0\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8505 --server.headless true
```

浏览器打开 `http://127.0.0.1:8505`（仅本机访问，不公网部署）。
当前服务入口：`http://127.0.0.1:8505`，健康检查 `http://127.0.0.1:8505/_stcore/health`。

后台隐藏窗口启动（记录 PID 与日志；日志父目录需先创建）：

```powershell
New-Item -ItemType Directory -Force -Path "reports\p0" | Out-Null
$p = Start-Process -FilePath ".\.venv-p0\Scripts\python.exe" `
  -ArgumentList "-m","streamlit","run","app.py","--server.address","127.0.0.1","--server.port","8505","--server.headless","true" `
  -WorkingDirectory (Get-Location) -WindowStyle Hidden -PassThru `
  -RedirectStandardOutput "reports\p0\streamlit.out.log" -RedirectStandardError "reports\p0\streamlit.err.log"
$p.Id
```

健康检查与停止：

```powershell
.\.venv-p0\Scripts\python.exe scripts\p0\health_check.py http://127.0.0.1:8505/_stcore/health
```

停止方式（二选一）：

- 前台运行时：直接在运行窗口按 Ctrl+C。
- 后台运行时：先核实本项目 app.py 实际监听 8505 的进程 PID 再停止该进程；
  上面记录的 `$p.Id` 是启动器 PID，不保证等于 Streamlit 监听进程的 PID。
  不要盲目杀端口或结束所有 python 进程。

## 七 数据位置

- 存储根：`data/p0/store/objects/<sha 前两位>/<sha256>`
- 数据库：`data/p0/agrolake.sqlite`
- 导出报告：`data/p0/reports/`

可用环境变量覆盖：`AGROLAKE_DATA_DIR`、`AGROLAKE_STORE`、`AGROLAKE_DB`、`AGROLAKE_REPORTS`。

## 八 常见问题

- 上传 TIFF/GeoTIFF：本治理页不支持，请到第 8 页“田块识别”使用专门的 8 波段识别模型
  （见[网页识别说明](网页识别.md)）；治理页不使用 Pillow 伪装多波段栅格。
- 未填来源：网页导入表单在提交前就要求必填来源，不会放行空来源；
  后端质检对确实缺失来源的入库记录判为阻断（required_source），可在“问题处置”补充来源并复检。
- 重复内容：仍生成新的导入事件与版本，标记为 duplicate，不覆盖原对象。
- 隔离后复检：状态保持 isolated，需在处置页显式“解除隔离”。
- 坏图/空图：页面跳过预览，改为显示文件名、质量问题与“在问题处置隔离或替换文件”；
  未知元数据显示“未知”，不冒充真实测量，也不暴露原始解码异常。
- 报告下载：生成后下载按钮在本会话普通 rerun 后仍保留；下载内容是“生成时”的快照，
  数据变化后请重新生成，不会自动把不同批次当作最新报告。

## 九 网页田块识别入口（第 8 页）

网页新增第 8 个页签“田块识别”，通过 HTTP 调用本机识别服务运行 FTW v1 8 波段模型。
它需要先启动识别服务，再启动本页网页：

```powershell
# 窗口A：识别服务（默认 127.0.0.1:8506）
& '.\.venv-p0\Scripts\python.exe' '.\scripts\service\serve.py'
# 窗口B：网页
& '.\.venv-p0\Scripts\python.exe' -m streamlit run app.py --server.address 127.0.0.1 --server.port 8505 --server.headless true
```

打开 `http://127.0.0.1:8505` 切到“田块识别”。识别服务未启动时该页只给出启动提示，
前 7 个治理页不受影响。当前边界：仅支持 8 波段 TIFF；候选连通区域不是经验证的真实
田块数；没有真值不报告准确率、不换算平方米；DeepSeek 问答尚未接入。
详见[网页识别说明](网页识别.md)。
