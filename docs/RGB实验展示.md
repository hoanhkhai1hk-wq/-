# RGB识别实验展示

启动已有网页后，打开 [AgroLake](http://127.0.0.1:8505/)，在侧栏选择“RGB 识别实验”。启动方法沿用[本地启动说明](本地启动.md)，不需要另装依赖。

1. 看顶部训练状态。进度来自最近保存的检查点，点击“刷新结果”读取最新记录；训练结束后仍需独立复核才能发布新图。
2. 在“选择图片案例”选R01、R03、R05、R07、U10或U11，再选择固定训练编号。原图、无增强对照与亮度扰动按同一顺序展示，三组都保留。
3. 黄色表示模型预测田埂，灰色表示预测道路。先对照原图看田块内部误涂、窄带漏检，再看对应像素统计；可下载当前对照图或全部统计CSV。

R系列参与过训练；U系列保留作局部参考，完整边界尚未审核。表内IoU只计算已有有效参考像素，未确认区域不参与。全部分数均不是独立测试精度，面积仅为像素，不是平方米或真实田块数。

本页只读取已保存的本地产物。查看、切换、刷新和下载均不启动模型、不修改标注。FTW双时相8波段识别仍在“田块识别”页，输入协议不受影响。

## 结果入口

展示清单位于 `reports/rgb/current-results.json`，格式为 `agrolake_rgb_results_view_v1`。面板与统计必须携带SHA-256，文件仅允许来自项目内 `outputs/` 或 `reports/rgb/`；摘要不符或更新未完成时显示提示。

训练中的记录明确区分旧结果与尚待复核的新训练。最终清单由Codex在独立核验后发布，不按最高分挑选训练编号或检查点，也不自动替换模型。实验的详细条件、完整三组对照和核验报告留在本机 `outputs/` 与 `reports/rgb/`，不随源码提交大图、数据或权重。
