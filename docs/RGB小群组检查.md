# RGB 小群组可拟合性检查

全734张训练的田埂漏分尚未解决。先检查同一张图能否在少量图片共同训练时拟合现有标注，以缩小后续排查范围。工具是`scripts/rgb/cohort_probe.py`，仅执行记忆检查，不发布候选模型。

## 本轮固定条件与结果

使用原有734张实验范围、128×128输入、同一29,779参数SmallUNet、seed20261017、Adam学习率0.001、不增强。权重统一取**全部734张**的平方根逆频，不随小群组改变。每组从相同参数重新初始化，每步看完整群组，固定300次更新，每张恰好被看300次。记录0/50/100/200/300步，以下只取固定最后一步。

表中始终是同一张已见问题图`d6b1d7c1681b10f770d7`（`hy0713 (1)/tile_r68_c43.tif`）的田埂指标，并非群组平均：

|训练内容|田埂precision|田埂recall|田埂IoU|
|---|---:|---:|---:|
|007：只训练该图|87.69%|99.96%|87.65%|
|008 ridge4：该图加3张田埂问题图|80.13%|95.83%|77.43%|
|008 mixed8：上述4图再加4图|99.76%|50.46%|50.40%|

群组整体田埂IoU另为ridge4 **51.63%**、mixed8 **25.66%**；它们覆盖不同图片，不与表中单图数字混作同一统计量。

加入其他图片后，这张图在固定训练预算下更难拟合。群组组成、一次更新的平均目标和计算量也随之改变；这些结果不能证明标签冲突、容量不足或某个优化因素是唯一原因。4/8图检查也不是原734图训练过程的缩小复现。旧004模型和默认训练策略保留，007/008模型均不晋升为候选。

这是与现有训练标注的一致性，不是独立农业准确率。来源、时间、Fieldridge含义仍未知；48份排除、121份含未确认别名的整图暂缓继续有效，没有独立验证/测试划分。

## 如何运行

先准备一个新配置文件，放在`reports/rgb/`下，输出目录必须与配置和选集所在目录互不包含。配置示意：

```json
{
  "schema_version": 1,
  "selection_sha256": "当前selection.json文件的SHA256",
  "cohorts": [
    {"name": "example2", "sample_ids": ["允许实验训练的ID1", "允许实验训练的ID2"], "reason": "选择依据"}
  ]
}
```

实际008配置在`reports/rgb/Codex-cohort-20261017-008/cohorts.json`。以下使用它运行一次新检查；`manual-cohort-01`必须尚不存在：

```powershell
& '.\.venv-recognition\Scripts\python.exe' -B 'scripts/rgb/cohort_probe.py' --selection 'reports/rgb/TRN-20261017-003-selection/selection.json' --cohorts 'reports/rgb/Codex-cohort-20261017-008/cohorts.json' --output 'reports/rgb/manual-cohort-01' --steps 300 --size 128 --seed 20261017 --threads 4
```

只使用已有recognition环境，不下载模型。默认300步，允许1—500步；尺寸32—256且为8的倍数；线程1—8。学习率可用`--learning-rate`显式指定，默认仍0.001；须为有限数值，范围1e-6—1e-2，API拒绝bool/字符串/NaN/Inf等非法值，输出前失败。`--base-width`仅接受整数8或16，默认8直接使用原SmallUNet；16仅在probe中把通道改为16/32/64，继承相同forward。根/组摘要和专用checkpoint记录实际学习率、宽度、通道和参数量，原root/learning_rate参数位置兼容。最多8组，每组1—16个不重复ID，组名必须安全且忽略大小写后唯一。所有ID须在选集中标为`experiment_train`；不能通过配置重新纳入排除/暂缓图片。

工具先重新核对全部原图/原JSON、manifest、policy、选集决定与mask摘要，再开始训练。每组独立优化器、相同初始化；检查实际更新次数、曝光次数、loss/梯度/参数有限及参数改变，保存后严格重载核对。选集或配置运行中发生改变时不能发布成功摘要。训练超过300步时也保留300步记录，便于比较固定训练预算；300步默认行为不变。

## 看哪些产物

- 根`summary.json`：两个群组的来源绑定和最后整体指标。
- 每组`summary.json`：所有里程碑、逐图/全组混淆矩阵、权重、更新与曝光次数、参数和文件摘要。
- `final_per_image.csv`：每图固定最后一步田埂指标。缺失分母留空，JSON中为null；不补0或1。
- 每图PNG与`-comparison.png`：128×128预测及原RGB/现有标注/预测三联图。预览是诊断像素最近邻放大2倍，不是512原分辨率推理。绿色田块、黄色田埂、红色道路，标注灰色为忽略。
- `probe_checkpoint.pt`：专用`agrolake_rgb_cohort_probe_v1`，标为`not_candidate_model=true`。正常候选预测和全量诊断入口都会拒绝，避免误作正式模型使用。

混淆矩阵真实为行、预测为列；0是田块，255不计分母。中间记录保留完整，只有最后模型另存checkpoint，不能声称已重新推理验证每个中间模型。

实际输出：`reports/rgb/TRN-20261017-008-cohort-probes/`。独立复核从原RGB、原mask和两个checkpoint重新推理全部12个末态预测，逐像素复算矩阵并检查三联图、CSV和摘要；证据在`reports/rgb/Codex-cohort-20261017-008/independent-actual.json`。

## 图块一致性只读检查

009仅在734张原图的64×64、步长64网格上寻找**RGB完全相同**的跨图纹理块，纹理条件为最大单通道空间标准差大于5。有命中时才对双方均非255的mask像素比较类别；相同RGB也不能判定哪份标注正确。

实测46,976块中46,846块满足纹理条件，130块跳过，跨图完全相同命中0。独立复核换用BLAKE2b并保存每个摘要的全部出现位置，同样无跨图命中。结果在`reports/rgb/TRN-20261017-009-patch-audit/`。

这是网格对齐、完全相同图块的有限搜索，不能排除任意偏移、缩放、光照变化或近似重复，也不能证明标签一致、来源独立或同一时相。因此本轮仍不建立独立数据划分或改标注。

## 010：相同8图的预算与初始化检查

事前指定seed20261017、20261018、20261019，各从头训练500步。固定008的mixed8及顺序，输入/权重/模型/Adam/线程/全群组更新不变，没有按结果挑seed。只增加>300步时保留300里程碑；默认300步和500步上限不改。

下表左侧为**8图合计**田埂IoU，右侧为**同一固定问题图**田埂IoU，二者不混作同一指标：

|初始化seed|8图300步|8图500步|固定图300步|固定图500步|
|---|---:|---:|---:|---:|
|20261017|25.66%|65.85%|50.40%|84.96%|
|20261018|1.09%|60.51%|1.51%|86.23%|
|20261019|0.00%|17.32%|0.00%|26.61%|

原seed17的0/50/100/200/300步全部逐图指标、混淆矩阵和loss与008完全一致。固定同seed的300→500比较因此支持：在这组图片与条件下，增加训练预算能改善拟合。三次最终整体田埂IoU仍相差较大，不能称训练方案稳定，不能只展示较好的两次。三次500步中位数60.51%只是这三次的描述统计，**不是独立精度、置信区间或选出的正式模型成绩**。

本轮不从这3个seed中挑候选，不替换旧004。它也不能证明原734图只要增加训练就能解决问题，不能证明标签冲突或模型容量问题已排除。后续先在固定小群组和同3个seed上单独检查优化设置（例如学习率），再决定是否值得进行全734图实验；不自动改标签。

各次独立结果在`reports/rgb/TRN-20261017-010-seed17/`、`seed18/`、`seed19/`（后两者同前缀）。每次500实际更新、8图各500曝光，均为专用非候选checkpoint。24份末态预测和对照图已从原RGB/mask/CP独立重算；所有记录的矩阵/指标算术复核，但没有保存中间CP，不声称重新推理过中间态。

汇总表/图在`reports/rgb/TRN-20261017-010-stability-summary-v2/`；PNG和可导出SVG展示所有记录点，连线只是连接记录，不代表中间过程单调。初版图例与线条重叠，保留原`...-stability-summary/`，新版调整图例位置，数据相同。核验在`reports/rgb/Codex-stability-20261017-010/`。

重复新实验时输出必须换为未存在的新目录，例如：

## 011：学习率配对检查

事前只指定一个新值0.0003，与010已有0.001结果按seed配对。仍为同8图/顺序、同3seed、各500步和同一初始化，其余条件不变，不重跑旧实验、不追加搜索、不挑最好一次。

|seed|0.001的8图田埂IoU|0.0003的8图田埂IoU|新减旧（百分点）|
|---|---:|---:|---:|
|20261017|65.85%|34.00%|-31.86|
|20261018|60.51%|46.34%|-14.17|
|20261019|17.32%|74.71%|+57.39|

较小学习率前两次下降、第三次明显提高，没有一致胜出。三次的观察范围从48.53缩到40.71个百分点，但中位数从60.51%降到46.34%；这些都是三次已见图拟合的描述统计，不能仅凭范围缩小称稳定性问题解决，也不是置信区间或农业精度。因此默认保持0.001，旧004和所有旧结果保留，新probe不晋升候选。

同一固定问题图的500步IoU按seed分别从84.96/86.23/26.61%变为67.31/85.97/86.44%，不能用其中一个样本替代8图整体指标。三个初始参数摘要和0步全部记录逐seed与010一致，末态24份预测/面板/CSV/矩阵/loss/来源从原RGB/mask/CP独立重算通过。正常候选预测和诊断入口拒绝专用CP。

结果在`reports/rgb/TRN-20261017-011-seed17/`、同前缀`seed18/`、`seed19/`；配对表和PNG/SVG图在`...-011-lr-summary/`，独立证据在`reports/rgb/Codex-lr-20261017-011/`。复现时换新目录：

## 012：标签缩图损失只读检查

另对734张原512×512候选mask，分别NEAREST缩到128/256再最近邻还原512，检查现有标注细节损失，未训练新模型。

|标签往返分辨率|田埂IoU|道路IoU|田埂在缩图后整图消失数|道路整图消失数|
|---|---:|---:|---:|---:|
|512→128→512|96.70%|99.17%|0|0|
|512→256→512|98.37%|99.40%|0|0|

原255不计分母，还原新增255对原已知像素按漏失计入FN，不能借忽略掩盖损失。矩阵真实行0/1/2、还原列0/1/2/255。全部1468次缩图/还原经独立整数索引逐像素核验，并从原mask另用histogram2d重算保存矩阵、指标/CSV/面板。输出`reports/rgb/TRN-20261017-012-mask-resolution/`，证据`reports/rgb/Codex-resolution-20261017-012/`。

128标签往返没有造成类别整图消失，合计标签重合度较高；这不能证明分辨率对RGB识别无影响，未测RGB纹理损失，**也不是模型性能上限或农业精度**。不能把96.70%与模型128训练IoU相减解释为一个已知原因。后续先固定小群组检查模型容量/训练可拟合性，再决定是否扩大734图或提升分辨率；不自动修标签。

## 013：网络宽度对照

固定同8图/顺序、seed20261017/18/19、128输入、500更新、每图500曝光、4线程、Adam0.001及全734平方根逆频，只把通道8/16/32加宽到16/32/64。参数量29,779→118,307。比较相同更新预算，计算量未匹配；相同seed编号也不代表相同初始权重，不能单独证明容量是根因。

|seed|原网络500步田埂IoU|宽网络300步|宽网络固定500步|
|---|---:|---:|---:|
|20261017|65.85%|0.22%|71.89%|
|20261018|60.51%|82.46%|0.00%|
|20261019|17.32%|77.49%|81.11%|

全部为8图合计指标。宽网络两次末态提高，但第二组从300步82.46%退到固定500步0%，没有稳定解决漏分。三次500步中位数71.89%高于旧60.51%，观察范围却从48.53扩大到81.11个百分点，不能只挑较好两次或把300步冒称末态。保留旧004和默认策略，不晋升probe。

宽网络参数/梯度/loss全部有限、实际更新/曝光和保存重载通过，不能因有限数值就认定训练稳定。独立构造宽网络（不调用训练模型工厂）核初始化、0步预测及所有24末态预测/指标/CE/CSV/面板/来源，全部相符；中间记录只核算术，没有中间CP，不声称已重推300步模型。

结果`reports/rgb/TRN-20261017-013-seed17/18/19`（同前缀）、`...-013-width-summary/`，独立证据`reports/rgb/Codex-width-20261017-013/`。复现时换新目录：


下一步优先在发生回退的固定小群组记录更细的损失、梯度范数及中间模型，定位优化不稳定，再考虑扩大734图实验，不继续盲目增大网络或挑最好结果。
