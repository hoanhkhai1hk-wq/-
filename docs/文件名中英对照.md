# 文件名中英对照

给不熟悉英文时使用。左边是磁盘上的真实文件名（不要改），右边是它干什么。
多数模块开头有用途说明，部分识别模块使用英文；可用本表或根目录中文导航定位。

## 一、根目录

| 文件名 | 中文含义 | 作用 |
|---|---|---|
| `app.py` | 网页主程序 | Streamlit 网页入口，运行它才有操作界面 |
| `README.md` | 项目说明 | 项目简介、启动方式、当前进度 |
| `THIRD_PARTY.md` | 第三方登记 | 用到的开源代码、模型、数据的来源与许可 |
| `requirements-p0.txt` | 治理环境依赖清单 | 治理部分需要装的包 |
| `requirements-p0.lock.txt` | 治理依赖锁定版本 | 固定37项依赖版本；还需匹配Python和系统环境 |
| `requirements-recognition.txt` | 识别环境依赖清单 | 识别部分需要装的包 |
| `requirements-recognition.local.lock.txt` | 识别新增依赖锁 | 6个小包版本/哈希；继承的CPU Torch环境另见模型适配说明 |
| `.gitignore` | 不入库清单 | 列出不进 Git 的目录和文件类型 |

## 二、`agrolake/` 治理核心（已验收）

| 文件名 | 中文含义 | 作用 |
|---|---|---|
| `config.py` | 配置与路径 | 数据库在哪、文件存哪、各种参数 |
| `db.py` | 数据库 | SQLite 建表、连接、读写 |
| `storage.py` | 文件仓库 | 按 SHA256 存原文，内容相同只存一份 |
| `ingest.py` | 数据接入 | 把 JPG/PNG 影像、CSV 属性、JSON/TXT 记录收进库 |
| `quality.py` | 质量检查 | 跑质量规则，标出模糊、缺值、重复等问题 |
| `semantics.py` | 口径标准化 | 单位换算、地物类别统一叫法 |
| `scenes.py` | 场景关联 | 把影像和它的属性、记录关联成一次作业场景 |
| `disposition.py` | 问题处置 | 补元数据、隔离、标重复、复检 |
| `reporting.py` | 报告导出 | 导出 CSV / JSON / Markdown 清单 |
| `__init__.py` | 包标识 | 让 Python 能把 `agrolake/` 当成一个包来 import |

## 七、不进 Git 的目录（看得到但不入库）

| 目录 | 中文含义 | 里面是什么 |
|---|---|---|

## 关于"能不能改成中文文件名"

当前保留英文模块路径，使用中文导航显示用途。这样可以阅读中文说明，同时沿用现有导入、测试和文档引用。若以后确需改名，再统一调整引用并运行相关测试；本次没有重命名代码文件。
