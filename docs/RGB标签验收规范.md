# RGB标签验收规范

版本：**V1（RGB-LABEL-V1）**。性质：**本项目约定，不是行业标准**。本规范随本单完成核验并本地提交后，对该提交之后**后续新接入**的RGB图片及其标注验收生效；不按照片拍摄日期倒推生效，不追溯改判历史标注。文件与登记编号使用用户指定的20261022，生效条件以验收提交为准。

本次只定规范、整理例图并登记疑义；不修改模型权重、融合规则、阈值，不训练、不推理，不自动修改、补画或删除任何已有标签。规范本身不使任何历史资料自动变成语义已审核或训练就绪。

## 1. 固定类别与判定次序

| 像素值 | 类别 | 注意 |
|---|---|---|
| 0 | 田块（Field） | 不是背景；含符合下表条件的田面内裸土 |
| 1 | 田埂（Field ridge） | 依据田界位置、窄条带形态与分隔作用，不仅依据颜色或材质 |
| 2 | 道路（Road） | 满足下表条件的土路或硬质路面主体 |
| 255 | 未知/忽略 | 未画、无法判定、跨类重叠、待审未决；不补成背景或其它类别 |

先查位置和作用，再查是否独立条带及通行证据，最后辅助观察颜色、材质与同场景相对宽度。能否通行、分隔田块的作用或宽窄关系不清时登记待审，不强行套入0/1/2。

### 相对宽度与通行证据的操作方法

1. 只与**同场景相邻、作用可核实的田埂**比较横向宽度，保留对照位置和上下文；不同拍摄高度、地面分辨率或裁切长度的像素数不直接比较。
2. 通行依据可以是可核实的连续通路、与出入口的连接关系、可见通行设施/车辆或明确业务资料；单有车辙、亮色、平直形状或局部加宽，不足以认定道路用途。
3. “明显宽于”不在V1中换成任意固定像素数、米数或比例阈值；若对照与通行作用不能可靠确认，则登记待审，后续新接入的未决区域保留255。
4. 该相对判断用于人工语义验收，不写入模型后处理，不调整当前W5道路支持条件、融合或阈值。

## 3. 255未知、重叠与未画区域

- **无法判定或类别重叠→255未知，不补标**。255不是背景；0仅代表明确的田块，未画区域不能默认变0。
- 现有机械转换策略保持：同类并集；不同类别覆盖冲突部分为255；未画部分为255。几何审核与语义审核分开，几何通过不代表语义正确。
- 对本次历史开发资料，255只是待审建议和既有转换语义，不把任何已有0/1/2自动改写为255；不补画未知多边形、不删除原多边形。
- 网页字典存在沟渠名称，但当前RGB像素类别没有独立沟渠ID；明确或疑似沟渠不能强行改称田埂。历史已确认沟渠保持原语义记录与既有255，两侧田埂分别判断。
- `Fieldridge→Field ridge`仍只是历史派生层拼写归一假设；本规范不会自动批准所有别名实例。

## 4. 历史事实、既有类别规范页与本规范的关系

历史依据见[标注审核参考](标注审核参考-20261019.md)：E03水泥细边可为田埂；E04道路旁普通绿带不自动算田埂、已有“不标”保留255；长草田埂仍是田埂。V1明确“路面主体”“田界分界”的适用对象，保留这些已确认事实，不反转历史决定。若今后发现实质矛盾，停止该项验收并报告，不静默覆盖。

E04在本规范中仅引用已有文字事实，不取其图片作为本轮例图；本轮取图严格限于新313张和旧734张开发侧允许清单。

网页“类别规范”实际为`app.py`的类别字典与标准化页面，读取`configs/semantic_rules.json`（SEM-1.0.0），负责名称/别名、字段、单位与原值映射。它**不是逐像素标注验收标准**。RGB类别对应字典田块FIELD、田埂FIELD_BOUNDARY、道路ROAD；字典DITCH存在不等于RGB模型新增沟渠类别。本规范补充后续新接入的场景判定，不改页面、字典配置或历史映射版本。机械转换继续按[RGB候选数据准备](RGB候选数据准备.md)的原规则执行。

## 5. 后续新接入验收与疑义登记

1. 保存原图/标注原件，记录来源图片编号、来源声明、许可说明、尺寸、SHA256、标注版本与适用规范V1；缺失来源/授权如实记录，不编造。
2. 核对图与JSON对应、类别值、坐标和自交等几何问题；输出几何审核结果，不修改原件。
3. 按五类表逐区域复核位置、形态与作用。记录明确依据；不能只依据颜色或材质判类。
4. 每个疑义登记唯一编号、图片/关注区域、疑点、条件性建议、状态=待审。建议不是判定；待审前不补标、不改标。审核结论与后续获授权的修订各用新记录/新副本保留，不覆盖历史。
5. 语义、几何、来源/许可状态各自记录；未决件不自动进入训练就绪。例图不证明来源地块关系或整批语义已成立，不包装成正式独立测试集。

## 6. 版本与证据边界

V1只对验收提交之后新接入生效；历史标签、模型、融合、阈值、治理库均不因本规范发生变化。新版若调整口径，应另记版本、变化项与新接入范围，不无声追溯改判。

上一轮诊断中的2.28%是特定边界定义下的边界带相关误差上界估计，不是因果证明；新旧田埂外观不同是已观察现象，尚不能断言为唯一或已证主因。土路历史归类是否统一尚不能确认。本规范建立前向约定，不把上述未证事项写成既定事实，也不承诺精度提升。
