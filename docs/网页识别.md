# 网页田块识别：启动、演示与查看

第8页成功结果新增“治理登记与血缘追溯”：点击登记输入资料，将服务端输入登记单JSON纳入P0文本资产，查看登记时与当前质量、人工复核和产物关系并下载JSON。详细操作及边界见[治理识别血缘](治理识别血缘.md)。登记不触发推理，登记单文本质检不代表原TIFF质检。

版本 0.1.0（2026-10-15，DEV-20261015-012）。面向 Windows PowerShell、零基础。
本页说明如何在本机把**识别服务**和**操作网页**一起启动，并在网页第 8 个“田块识别”页
提交一张 8 波段 TIFF、查看结果与下载产物。

> 本说明基于本机实际运行的验证，不代表一台全新电脑无需准备环境即可运行；
> 新机器的完整依赖安装尚未实测。

## 一 两个进程的分工

- **识别服务**（`scripts/service/serve.py`，`.venv-p0`）：接收上传、排队、调用真实
  模型子进程（`.venv-recognition`）、把来源/场景/模型摘要/候选区域/产物校验写入 SQLite。
  默认 `http://127.0.0.1:8506`。它只绑定本机地址。
- **操作网页**（`app.py`，Streamlit，`.venv-p0`）：第 8 页“田块识别”作为前端，
  通过 HTTP 调用上面的服务。网页进程**不加载模型**，也不直接写识别数据库；
  它只负责展示与下载。

两者都用同一个 `.venv-p0` 解释器；真实推理始终发生在识别服务拉起的
`.venv-recognition` 子进程里。网页只允许连接本机地址（`127.0.0.1` / `localhost` / `::1`）。

## 二 启动顺序

先启动识别服务（窗口 A），再启动网页（窗口 B）。

窗口 A：

```powershell
Set-Location 'D:\AI_Workspace\Tasks\兴智杯'
$env:PYTHONDONTWRITEBYTECODE = '1'
& '.\.venv-p0\Scripts\python.exe' '.\scripts\service\serve.py'
```

预期显示：`识别服务已启动： http://127.0.0.1:8506/`。这一行只有在服务真正运行时才可用。

窗口 B：

```powershell
Set-Location 'D:\AI_Workspace\Tasks\兴智杯'
$env:PYTHONDONTWRITEBYTECODE = '1'
& '.\.venv-p0\Scripts\python.exe' -m streamlit run app.py --server.address 127.0.0.1 --server.port 8505 --server.headless true
```

浏览器打开 `http://127.0.0.1:8505`（仅本机），切到第 8 个页签“田块识别”。

如果只启动网页、没有启动识别服务：第 8 页会给出“识别服务当前不可用”的中文提示与
启动命令，并说明前 7 个治理页仍可正常使用；不会因为服务未启动而让整个网页报错。

## 三 页面使用流程

1. **选择输入**：
   - “使用本机公开适配样例”：仅当样例文件存在且 SHA256 与本机记录的固定公开摘要一致时可用。
     这是上游公开适配样例，来源/许可为上游公开说明；**时相身份未独立确认**，不是自采农业观测。
   - “上传自己的 8 波段 TIFF”：`.tif/.tiff`，≤40 MiB。普通 JPG/PNG 或 3 通道 RGB
     不适配本模型，网页不会把它们伪装成 8 波段。
2. **填写来源与场景**（必填）。来源链接、许可状态可留空；许可字段是你填写的**声明**，
   系统不会自动替你取得授权。公开样例会预填真实来源说明，可自行修改。
3. **点击“开始识别”**：填写输入后显式提交。每次提交持有稳定的请求号；
   若提交超时或响应不完整、结果未知，会提示“重试提交（同一请求号）”，复用同一请求号，服务端按
   请求号幂等，不会重复执行。普通刷新、切页、切换任务、下载都**不会**重复提交；
   同一浏览器会话中，相同输入和来源/场景声明再次点“开始识别”会复用原任务。
   原任务成功、失败或中断后，点**“重新识别（新任务）”**才为相同输入另开一次运行；
   原任务仍在排队或运行时不会另开。更换输入或声明后点击提交也会使用新请求号。
4. **查看状态**：`排队中 / 运行中 / 已成功 / 已失败 / 已中断`。可点“刷新状态”，
   或勾选“自动刷新（每 2 秒，最多 60 次）”。服务重启后未完成的任务标记为“已中断”，
   不会自动重放；本会话原输入仍保留时可点“重新识别（新任务）”。
5. **查看历史**：下拉选择历史任务即可查看详情，不依赖浏览器内存；刷新页面后仍能从
   服务重新读回。
6. **成功结果**：显示 `preview.png`（左：输入前三波段拉伸 / 中：预测类别 / 右：叠加，
   非真值）、背景/田块内部/边界/无效像素数量、候选区域表（编号/像素/边框），以及
   五个产物下载。
7. **下载**：`mask.tif`、`preview.png`、`class_pixels.csv`、`field_pixels.csv`、`run.json`。
   下载时会再次核对服务保存的摘要；文件被改动或过期时服务返回 409，网页明确报错并
   停止展示本任务产物，不会静默交付过期结果。成功任务缺少五份完整校验记录时也不会展示结果。
8. **服务断开后恢复**：重新启动窗口 A 的服务，再点“重新连接识别服务”。任务历史从
   同一数据库读回；恢复连接不会自动提交新识别。浏览器整页重载会清空本会话的上传与请求号，
   此时应先查历史，再决定是否另开任务。

## 四 结果怎么读（重要边界）

- 固定公开样例本机实测：背景 105910、田块内部 74580、边界 38572、无效 0，共 219062 像素；
  田块内部 **722 个候选连通区域**。
- **候选连通区域不等于经验证的真实田块数**，只是像素级 4 连通统计。
- 没有独立真值，**不报告准确率/IoU**；面积只以像素计，未取得经核验的地理参考前
  **不换算平方米**。
- DeepSeek 问答尚未接入；本页只展示识别服务返回的事实，不含 AI 回答。

## 五 人工复核记录（可选）

任务**成功后**，成功结果里会出现“**人工复核记录**”面板，用于记录人工意见（DEV-20261015-013）：

- 可对**任务整体**或**某个候选区域**填写结论（可用/存疑待核实/不采用）、复核人署名与原因；
  任务整体结论与区域结论分开，不把一处区域可用视为整个任务已确认。
- **只有点击“保存”才写入**；普通刷新、切换任务/历史、下载都不会写库。相同内容重复保存复用同一
  请求号、服务端幂等不重复写；修改署名/结论/原因后再保存按新意图追加一条。
- 提交回执未知时给出“重试提交（同一请求号）”，不会悄悄换号重复写；切换任务不串旧意见。
- 可查看当前意见与不可覆盖的历史，并导出 UTF-8 CSV/JSON（均注明人工声明与像素/无真值边界；
  CSV 对以 `= + - @` 开头的文本前置单引号防公式执行，原值见 JSON）。
- 人工意见**不改**掩膜/类别数/模型输出，**不代表**真值、精度提升或真实面积；复核人只是本机署名。

完整用法与接口见[人工复核说明](人工复核.md)。

## 六 停止

- 识别服务（窗口 A）：按 `Ctrl+C`。服务停止接收新作业，结束自己正在执行的识别进程树，
  未启动的排队作业标记为“已中断”。异常退出后再次启动会把遗留作业标记中断，保留输入与日志。
- 网页（窗口 B）：按 `Ctrl+C`。
- 同一数据库/存储/运行目录只允许一个识别服务实例；误开第二个会拒绝启动。
