## 这是什么

用已有的 CPU Torch 环境，通过 segmentation-models-pytorch 0.5.0 直接构建 `smp.Unet(encoder_name="efficientnet-b3", encoder_weights=None, in_channels=8, classes=3)`，并以 `strict=True` 加载 FTW v1 CC-BY 检查点中的全部 634 个 `model.*` 张量，对真实 8 波段 GeoTIFF 完成一次真实推理。

这**不是** ftw-tools 1.4.3 CLI，也不宣称数值与原 CLI 严格等价。

## 与 ftw-cli 1.4.3 的差异（明确记录）

| 项目 | 原 ftw-cli 1.4.3 | 本适配器 |
|---|---|---|
| 模型加载 | Lightning `CustomSemanticSegmentationTask.load_from_checkpoint` | 直接 `torch.load(weights_only=True)` + SMP strict 加载 |
| TIFF 读取 | rasterio/GDAL | tifffile（未安装 GDAL/rasterio） |
| 采样 | torchgeo `GridGeoSampler` + DataLoader 多进程（num_workers=6） | 单进程、torch 2 线程的固定网格滑窗 |
| 边缘像素 | 窗口内 strip 写回，图像边缘留在初始化的 0（隐式背景） | 整图 reflect 补齐后滑窗，保证每个有效像素落入某窗口内部并得到真实预测 |
| 上/下采样 | kornia bilinear ×2 / nearest | torch F.interpolate bilinear ×2 / nearest（同方式） |
| 预处理 | `/3000`（ftw.datamodules.preprocess） | 相同：`/3000` |
| NoData | 输出 nodata=0 | 输出 nodata=255，非有限像素标 255，不冒充背景 |

参数：patch 256、padding 16、stride 224、resize_factor 2，与原推理一致。

## 排除项

检查点共 635 条 state_dict：634 条 `model.*` 全部严格加载；`criterion.weight`（训练损失权重）明确排除。任何缺失/多余/形状失配都会直接失败，不随机初始化、不忽略键、不换模型。

## 输入样本身份限制

`samples/ftw_smoke/inference-img.tif`（578×379×8，uint16，UTM 33N 标签齐全）是上游冒烟测试样本；其双时相窗口/波段顺序元数据不足，时相身份未确认。预览仅标注"第一组 RGB = 波段 1-3"。像素表为纯像素单位，不代表已验证平方米或稳定田块身份；未计算 m²、NDVI。

## 无真值即无精度

没有独立标注真值，本报告与 run.json 均不含 IoU/准确率。合成测试（tests/recognition/）只验证规则行为，不代表真实农业效果。

## 使用方法（PowerShell）

```powershell
# 在项目根目录运行。本机公开样本和模型文件已取得，未纳入Git。
$RunDir = Join-Path ".\reports\recognition\manual" (Get-Date -Format "yyyyMMdd-HHmmss-fff")
& ".\.venv-recognition\Scripts\python.exe" `
  ".\scripts\recognition\run_inference.py" `
  --input ".\samples\ftw_smoke\inference-img.tif" `
  --checkpoint ".\models\ftw-v1\3_Class_CCBY_FTW_Pretrained.ckpt" `
  --output-dir $RunDir `
  --expected-input-sha256 "da482e7987b36898bd9f8381e7c7fe95c05dfc5ccbba19a58eb65e544d1af750"
```

（Windows PowerShell 续行符是反引号 `` ` ``，不是 cmd 的 `^`。）

### 两种输入校验模式

- **固定冒烟**：加 `--expected-input-sha256 <SHA256>`，输入摘要必须与给定值完全一致，否则失败。用于对同一公开样本复跑。
- **普通输入**：省略该参数。输入**始终记录实际 SHA256**，并按真实的文件大小（≤40 MiB）、单页、8 波段、单边 ≤4096、总像素 ≤1048576、解码预估 ≤64 MiB 校验格式，不再硬编码唯一样本摘要。模型哈希固定校验（可信模型哈希 250 MiB 上限）。

### 输出目录约束

`--output-dir` **必须是不存在的新目录**：

- 目录已存在时直接以非零码退出，打印结构化失败，不写入、不覆盖，原结果逐字节保留（不会出现 error.json 覆盖旧文件、success 与 failure 混存）。
- 成功输出 mask.tif（原尺寸 uint8，0 背景 / 1 田块内部 / 2 边界 / 255 NoData，空间标签原样保留、GDAL NoData=255）、preview.png、class_pixels.csv、field_pixels.csv、run.json。
- 失败写 error.json 并以非零码退出。
- 若源图声明了数值型 GDAL NoData（tag 42113），命中的像素判为无效并输出 255；源未声明 NoData 时不假定任何值（含 0）。非有限像素（NaN/Inf）在插值与模型前中性填 0，绝不进入网络。空间标签或 NoData 回读不一致时直接判失败。
- RGB预览只用有效且有限的像素计算拉伸，无效位置显示灰色；少量NaN/Inf不会使整幅预览变黑。输入的时相身份默认未独立验证，不把普通用户输入标为上游样本。
