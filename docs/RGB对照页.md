# RGB训练诊断对照页

离线查看已有RGB训练结果，按同一图片、同一个初始化编号比较原网络和宽网络。页面不运行模型、不上传照片、不保存标注，也不改变原FTW网页。

## 怎么查看

本轮实际页面生成后位于`reports/rgb/TRN-20261017-014-gallery/index.html`，与`assets/`一起保留。用浏览器打开HTML，先选图片，再选初始化编号和类别。四幅图依次为原RGB、现有标注、原网络预测、宽网络预测；下方表格区分当前图片IoU与全部8图合计IoU。上一张/下一张按固定样本顺序循环，来源数据可以下载。

绿色田块、黄色田埂、红色道路，灰色为标注忽略像素，不计IoU分母。图片是128×128诊断像素最近邻放大，不能当作512像素原尺寸识别结果。IoU为空时显示“—”，不补0或100%。

全部8张都参与过训练，现有标签尚未语义复核、两批来源关系未知，没有独立测试。这是训练诊断展示，高重合度只表示拟合这些标注，不能称新农田准确率。相同seed编号在不同宽度网络中不代表相同初始权重，也不代表相同算力。新probe仍不晋升正式候选。

## 如何生成

工具`scripts/rgb/gallery.py`只读取已有专用probe报告、checkpoint和PNG，校验来源与像素/指标后再输出。它会构建模型验证权重形状，但**不调用前向推理或训练**。只使用现有recognition环境。

```powershell
& '.\.venv-recognition\Scripts\python.exe' -B 'scripts/rgb/gallery.py' --config 'reports/rgb/Codex-gallery-20261017-014/config.json' --output 'reports/rgb/manual-gallery-01'
```

输出目录必须尚不存在，与配置、选集和输入报告目录互不包含。重复运行会拒绝覆盖。配置schema1须绑定selection路径与SHA，指定实际steps/size，最多3对seed。每对分别给出reference_summary和experiment_summary路径，全部位于`reports/rgb/`内；只允许宽度8与16的专用cohort probe，选集、图片顺序、步数、分辨率、学习率一致。

核验包括：全部样本都在同选集experiment_train，来源SHA对应、无重复/排除/暂缓图片；专用CP SHA/schema/声明形状/有限参数，未语义复核/未独立测试/非候选flag；最终逐图与整体混淆矩阵算术；预测PNG值域、面板像素与预测/标注/指标一致；跨网络/seed原RGB和标注像素相同。所有输入在输出前再次核SHA，避免预检期间被修改。

## 输出与边界

- `index.html`：内联样式/脚本/数据，所有图片均来自本地`assets`，没有外部字体、脚本、图片或网络API。
- `assets/`：从既有诊断三联图逐像素复制的RGB、标注和两网络预测，按同尺度分开展示。
- `gallery.json`：全部已见图指标、来源摘要与样本关系。
- `manifest.json`：所有输入和派生文件的SHA、真实范围flag；本页没有执行推理。
- `README.md`：简明操作说明。

动态文本使用textContent，内联JSON转义尖括号等字符。图片读不到时页面提示保留完整assets目录，不能借失败图片隐藏结果。控件可用键盘操作，小屏改为2×2图。页面不提供修改原标签/删除数据或对任意新图推理的操作。

软件测试使用保留合成fixture检查：生成过程中禁止forward、像素/指标绑定、内联数据安全、源篡改/范围flag/不一致选集或顺序/越界路径/暂缓样本在输出前拒绝，以及已有输出拒绝。实际8图/3seed页面64个PNG资产及48份预测指标均与原RGB/mask/旧新结果独立核对。浏览器72种组合和288个显示单元格一致，1440/390无横向溢出、四图全加载、键盘焦点明显、前后翻页与下载一致，无外部请求或控制台错误。图片错误事件的提示与恢复已模拟验证。

浏览器工具不允许file协议，本轮实际浏览器用只监听127.0.0.1的临时服务验证，没有冒称通过工具直接双击实测。临时服务已正常退出、端口无监听，浏览器报告无打开标签；交付保留HTML和完整assets，未发布到外网。证据在`reports/rgb/Codex-gallery-20261017-014/`，范围与最终状态见014复核报告和项目共享记忆。
