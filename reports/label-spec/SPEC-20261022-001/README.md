# RGB标签验收V1对照例图集

所有例图仅来自新313/旧734开发侧，冻结24张未使用。正例指所示区域可用于解释本项目约定，不代表整张历史标签获重新批准；青框仅为关注区域示意，不是新增标注。

**证据缺口**：土路组C4的2正例均为“窄土带→田埂”分支，并复用C2同一来源。现有资料未能证明2张“可通行且明显更宽的土路→道路”，不以浅色硬化路面或机耕车辙冒充。
